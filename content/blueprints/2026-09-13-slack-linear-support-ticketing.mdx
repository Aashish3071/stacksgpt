## The Problem

Customers and colleagues ask for help in Slack. Requests scroll out of sight, nobody is sure who picked them up, and the same issue gets reported twice. Copying each message into your issue tracker by hand is slow, so some requests are simply forgotten.

## What You'll Get

- Every Slack message tagged with a ticket emoji becomes a ticket in Linear, your team's issue tracker.
- Each ticket has a clear title, a short summary and a priority written by AI.
- Messages that already have a ticket are skipped, so nothing is filed twice.

## How It Works

1. Someone adds the ticket emoji to a Slack message that needs attention.
2. On a regular schedule, the workflow finds those messages and checks whether they already have a ticket.
3. AI writes the ticket details and the workflow creates the ticket in Linear.

## What You Need

- A Slack workspace where you can add an app
- A Linear workspace
- An OpenAI account for the AI step
- An n8n account to run the workflow, either in the cloud or on your own server
- About half a day to set it up

## Build It Step by Step

1. **Download the workflow file** from the box above and import it into n8n: open a new workflow, then choose Import from File.
2. **Connect Slack.** Create a Slack app that can search messages in your support channel, install it in your workspace and add its token to n8n.
3. **Connect Linear.** Create an API key in your Linear account settings and add it to n8n.
4. **Connect OpenAI.** Add your OpenAI API key to n8n.
5. **Choose your channel and team.** In the Slack search step, replace the example channel `#n8n-tickets` with your support channel. In the Linear steps, choose the team that should receive tickets.
6. **Test it.** Add the ticket emoji to a test message, run the workflow once and check that a ticket appears in Linear.
7. **Turn it on.** Choose how often it should run, then activate the workflow.

## Copy-Paste Prompt

Use this in the AI step if you want to change how tickets are written:

```text
Analyze the incoming Slack support message.
Write a clear, action-oriented title for the issue.
Summarize the user's problem in two sentences.
Set a priority of Urgent, High, Medium or Low based on the tone and context.
Output valid JSON that follows the provided schema exactly.
```

## Good to Know

- **People decide what becomes a ticket.** Only messages someone tags with the emoji are processed, so casual conversation never turns into work.
- **Keep the duplicate check.** The Slack message ID saved in each ticket is what stops the same request being filed again on the next run.
- **Private channels need an invite.** Invite the Slack app to private support channels, or their messages will not be found.
- **Do not run it more often than you need.** Linear's documentation lists a limit of 2,500 requests per hour when you use an API key, and every run uses some of that.
- **Easy extras.** Add a step that replies in the Slack thread with the ticket link, or one that posts back to Slack when the ticket is closed.

## Technical Details

```
[Schedule Trigger]
        │
        ▼
[Slack: Search Channel for Ticket Emoji Messages]
        │
        ▼
[Linear: Skip Messages Already Filed]
        │
        ▼
[AI Model: Title, Summary and Priority]
        │
        ▼
[Linear: Create Issue with Slack Message ID]
```

- **Slack search:** uses Slack's search syntax to find messages with the ticket emoji in one channel.
- **Duplicate check:** looks for a Linear issue whose description contains the Slack message ID.
- **AI step:** an LLM chain with a structured output parser that returns the title, summary and priority.
- **Linear step:** creates the issue in the selected team and writes the message ID into the description.
