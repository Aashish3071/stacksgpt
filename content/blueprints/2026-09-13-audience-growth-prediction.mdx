## The Problem

Most teams check follower counts after the fact. By the time you notice growth has stalled, weeks of posting have gone by, and it is hard to tell which kinds of posts actually helped. Keeping a spreadsheet up to date by hand rarely lasts.

## What You'll Get

- A running record of your followers across channels in a Google Sheet.
- A simple projection of where your audience is heading if the recent trend continues.
- AI suggestions for content experiments to try next, clearly labelled as ideas to test rather than predictions.

## How It Works

1. Every day, the workflow records your follower numbers and recent post stats.
2. A calculation step works out your growth rate and extends the trend forward.
3. AI reviews the numbers and your recent top posts and suggests what to try next.

## What You Need

- Access to your social platform data, through each platform's API or a data provider
- A Google Sheet to store the history
- An OpenAI account
- An n8n account to run the workflow
- Confidence building a workflow from an example, because there is no ready-made file for this one yet
- About half a day to set it up

## Build It Step by Step

1. **Create your sheet** with one tab for historical metrics and one for projections.
2. **Connect your data sources.** In n8n, add steps that fetch follower counts and post stats for each channel you track.
3. **Connect Google Sheets and OpenAI** by adding their credentials in n8n.
4. **Add the calculation step** using the configuration in Technical Details below.
5. **Add the AI step** and paste in the prompt below.
6. **Save the results** to your projections tab.
7. **Run it once** to record your starting numbers, then activate the daily schedule.

## Copy-Paste Prompt

Use this in the AI step:

```text
You are a senior audience growth consultant analyzing multi-channel performance data for a technology executive.

Data inputs:
Current Audience: {{ $json.followers }}
Weekly Growth Rate: {{ $json.weeklyGrowthRate }}
Projected Audience (short term): {{ $json.day30Projected }}
Projected Audience (medium term): {{ $json.day90Projected }}
Top Recent Themes: {{ $json.topThemes }}

Generate a structured forecast in JSON format:
{
  "trajectoryAssessment": "Accelerating" | "Steady" | "Plateauing" | "Declining",
  "milestoneEstimate": "<estimated date for the next follower milestone I set, with the assumption used>",
  "possibleDrivers": ["<hypothesis>", "<hypothesis>"],
  "contentExperimentRecommendations": [
    {
      "format": "<e.g. Technical Deep Dive / Data Teardown / Founder Essay>",
      "hypothesis": "<why this format might increase follower growth>"
    }
  ]
}

Only use the data provided. Present explanations as hypotheses, not facts.
```

## Good to Know

- **Projections are estimates.** They extend your recent trend and cannot account for algorithm changes, viral posts or paid campaigns.
- **Patterns are not proof.** If a type of post coincides with faster growth, treat that as an idea to test, not a guaranteed result.
- **Ignore one-off spikes.** Leave posts far above your normal range out of the baseline so projections stay realistic.
- **Be gentle with APIs.** Space out requests so you stay within each platform's limits.
- **Looking for a ready-made file?** The [YouTube Channel Strategist](/blueprints/templates/youtube-channel-strategist) template researches what performs in a YouTube niche.

## Technical Details

No complete, importable workflow ships with this blueprint yet. The excerpt below shows how the key steps are configured. You still need to add the steps that fetch your channel data and connect everything.

```
[Schedule Trigger: Daily]
                   │
                   ▼
[HTTP Request: Fetch Channel Follower & Post Data]
                   │
                   ▼
[Code Node: Compute Growth Rates & Projections]
                   │
                   ▼
[OpenAI Model: Interpret Trends & Suggest Experiments]
                   │
                   ▼
[Google Sheets: Record Projections & Weekly Brief]
```

```json
{
  "name": "Audience Growth Projection (excerpt)",
  "nodes": [
    {
      "name": "Daily Trigger",
      "type": "n8n-nodes-base.scheduleTrigger",
      "typeVersion": 1.2,
      "position": [200, 300],
      "parameters": {
        "rule": {
          "interval": [
            {
              "field": "days"
            }
          ]
        }
      }
    },
    {
      "name": "Calculate Growth Projections",
      "type": "n8n-nodes-base.code",
      "typeVersion": 2,
      "position": [440, 300],
      "parameters": {
        "language": "javaScript",
        "jsCode": "const { followers, weeklyGrowthRate } = $input.first().json;\nif (typeof followers !== 'number' || typeof weeklyGrowthRate !== 'number') {\n  throw new Error('followers and weeklyGrowthRate must come from your data source.');\n}\nconst dailyRate = weeklyGrowthRate / 7;\nconst project = (days) => Math.round(followers * Math.pow(1 + dailyRate, days));\nreturn [{ json: { followers, weeklyGrowthRate, day30Projected: project(30), day90Projected: project(90) } }];"
      }
    },
    {
      "name": "Interpret Trends",
      "type": "@n8n/n8n-nodes-langchain.openAi",
      "typeVersion": 1.8,
      "position": [680, 300],
      "parameters": {
        "messages": {
          "values": [
            {
              "role": "system",
              "content": "You are a growth strategist. Review the follower numbers and projected trajectory. Summarize the trend and suggest content experiments to test. Label every explanation as a hypothesis."
            }
          ]
        }
      }
    },
    {
      "name": "Save Projection to Sheets",
      "type": "n8n-nodes-base.googleSheets",
      "typeVersion": 4.5,
      "position": [920, 300],
      "parameters": {
        "operation": "append",
        "documentId": "={{ $vars.FORECAST_SHEET_ID }}",
        "sheetName": "Projections"
      }
    }
  ]
}
```
