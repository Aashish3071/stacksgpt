## The Problem

Writing a well-researched article takes hours, and turning it into LinkedIn and X posts takes more. Most teams publish less often than they want to, or fall back on AI content that reads as generic and unsourced.

## What You'll Get

- Research on your topic from the live web, with sources you can check.
- A long-form article saved as a draft in WordPress, written in your house style.
- A LinkedIn post and an X thread based on the article, waiting for review.

## How It Works

1. You submit a topic or a link.
2. Perplexity researches it and AI writes an article in your house style.
3. AI turns the article into social posts, everything is saved as drafts and your editor is notified.

## What You Need

- A Perplexity account for research
- An OpenAI account
- A WordPress site, or another place you publish articles
- A Slack workspace, if you want editor notifications
- An n8n account to run the workflow
- A weekend to set it up

## Build It Step by Step

1. **Download the building blocks** from the box above:
   - [Turn Perplexity Research into Publish-Ready HTML](/blueprints/templates/perplexity-research-to-html) covers research and article writing.
   - [Write Blog Posts in Your Brand Voice for WordPress](/blueprints/templates/brand-voice-blog-writer) covers on-brand drafts saved to WordPress.
   - [Create and Schedule Branded LinkedIn Posts](/blueprints/templates/branded-linkedin-posts) covers researched LinkedIn posts.
2. **Create a WordPress application password** with editor permissions.
3. **Connect your accounts.** Add Perplexity, OpenAI and WordPress credentials in n8n.
4. **Build the flow:** a form for the topic, then research, then article writing, then a WordPress draft, then social posts, then a Slack message to your editor.
5. **Add your style rules** to the article prompt below: tone, words to avoid and how headings should look.
6. **Test with one topic** and read every draft before running more.

## Copy-Paste Prompt

Use this in the article writing step:

```text
You are a senior technology editor writing for technical leaders, engineers and product operators.

Topic Brief:
Title: {{ $json.title }}
Primary Keyword: {{ $json.keyword }}
Research Context: {{ $json.researchSummary }}

Draft an authoritative long-form technical article in Markdown.
Follow these editorial requirements strictly:
1. Do not use em dashes anywhere. Use commas, colons or full stops.
2. Structure the piece with an executive summary, how it works, step-by-step implementation and trade-offs.
3. Every claim must trace to a source in the research context. Leave out anything you cannot source.
4. Avoid empty filler phrases such as 'in today's fast-paced world'.
5. Include a comparison table or code block that illustrates the concept.
```

## Good to Know

- **Nothing publishes on its own.** Keep the WordPress status set to draft so an editor approves every post.
- **Check the sources.** Research tools can still return outdated or wrong facts, so read the citations before accepting a draft.
- **Keep a style sheet.** Put your brand terms and banned phrases in the prompt so every draft follows them.
- **Easy extras.** Add suggested SEO titles and descriptions, or translated versions of each article.

## Technical Details

```
[Form Trigger: Seed Topic or URL Brief]
                  │
                  ▼
[Perplexity API: Live Research & Citations]
                  │
                  ▼
[OpenAI Node: Draft Long-Form Post]
                  │
                  ├── Branch 1 ──► [WordPress Node: Stage Draft Post]
                  ├── Branch 2 ──► [Prompt Node: Generate LinkedIn Post]
                  └── Branch 3 ──► [Prompt Node: Generate X Thread]
                  │
                  ▼
[Slack Node: Alert Editor with Staging Preview Links]
```

The excerpt below shows how the research and drafting steps connect. It is not a complete workflow. When passing research into the social post steps, send only the key takeaways so prompts stay within the model's context window.

```json
{
  "name": "Multichannel Content Automation Pipeline (excerpt)",
  "nodes": [
    {
      "name": "Topic Brief Trigger",
      "type": "n8n-nodes-base.webhook",
      "typeVersion": 2,
      "position": [200, 300],
      "parameters": {
        "httpMethod": "POST",
        "path": "content-brief",
        "responseMode": "onReceived"
      }
    },
    {
      "name": "Perplexity Research",
      "type": "n8n-nodes-base.httpRequest",
      "typeVersion": 4.2,
      "position": [440, 300],
      "parameters": {
        "url": "https://api.perplexity.ai/chat/completions",
        "method": "POST",
        "sendHeaders": true,
        "headerParameters": {
          "parameters": [
            {
              "name": "Authorization",
              "value": "=Bearer {{ $vars.PERPLEXITY_API_KEY }}"
            }
          ]
        },
        "sendBody": true,
        "specifyBody": "json",
        "jsonBody": "={\n  \"model\": \"{{ $vars.PERPLEXITY_MODEL }}\",\n  \"messages\": [\n    {\n      \"role\": \"system\",\n      \"content\": \"Research the topic. Return key facts with cited sources.\"\n    },\n    {\n      \"role\": \"user\",\n      \"content\": \"{{ $json.topic }}\"\n    }\n  ]\n}"
      }
    },
    {
      "name": "Generate Long-Form Article",
      "type": "@n8n/n8n-nodes-langchain.openAi",
      "typeVersion": 1.8,
      "position": [680, 300],
      "parameters": {
        "messages": {
          "values": [
            {
              "role": "system",
              "content": "You are an authoritative technology journalist. Write a deep-dive article based only on the research provided. Use clear H2 and H3 headings, concrete examples and no buzzwords."
            }
          ]
        }
      }
    },
    {
      "name": "Stage Draft in WordPress",
      "type": "n8n-nodes-base.wordpress",
      "typeVersion": 1,
      "position": [920, 300],
      "parameters": {
        "operation": "create",
        "title": "={{ $json.title }}",
        "content": "={{ $json.articleMarkdown }}",
        "status": "draft"
      }
    }
  ]
}
```
