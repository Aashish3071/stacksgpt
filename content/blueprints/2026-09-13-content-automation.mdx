## What You're Building

An end-to-end multichannel content production and automation engine. Producing authoritative technical content requires hours of background research, drafting, formatting, and adapting long-form pieces into platform-specific social posts.

This workflow takes a single seed concept or URL. A Perplexity research node gathers verified citations, technical specs, and recent real-world examples. An OpenAI node structures the research into an authoritative long-form markdown article with code snippets and tables. Downstream nodes automatically spin the article into a LinkedIn carousel outline, an X thread, and a draft newsletter, queuing all assets into staging tables for human editorial sign-off.

## What Research APIs and Content Generators Can Handle

Pure chatbot prompting creates generic, unverified articles. Combining structured pipelines with research APIs enables:

1. **Grounded Fact Checking**: Queries the live web through Perplexity to incorporate verifiable benchmarks and current statistics.
2. **Structural House Consistency**: Enforces strict brand tone, heading hierarchies, and forbidden phrasing across every draft.
3. **Automated Cross-Channel Adaptation**: Generates tailored social spins without copying and pasting between multiple windows.
4. **Staging Review Isolation**: Keeps generated drafts in draft or pending status so no unvetted content publishes automatically.

## What You Need

1. A Perplexity API key for live search research capabilities.
2. An OpenAI API key with access to GPT-4o.
3. A CMS destination (WordPress REST API, Ghost, Notion, or GitHub markdown repo).
4. An active n8n instance.

## How to Set It Up

1. In WordPress or your CMS, generate an application password or API token with editor privileges.
2. In n8n, configure credentials for Perplexity (HTTP Bearer auth), OpenAI, and WordPress.
3. Import the workflow definition JSON provided below into your n8n workspace.
4. Customize your editorial guidelines and brand voice rules inside the master drafting prompt.
5. In the Slack node, specify your target editorial team notification channel.
6. Submit a test brief to run the complete research, drafting, and staging sequence.

## The Core Workflows

1. **Brief Ingestion**: Captures seed title, target audience persona, primary keyword, and required takeaways from an n8n form or webhook.
2. **Live Neural Research**: Calls Perplexity sonar-pro model to retrieve factual background data, competitor approaches, and cited references.
3. **Article Construction**: Formats the long-form piece into clean markdown complete with subheadings, actionable steps, and zero forbidden jargon.
4. **Social Derivatives**: Takes the finalized draft and produces platform-native social content with tailored hooks and character counts.
5. **Staging & Alerting**: Posts the article into WordPress as a Draft and notifies editors in Slack with links to review and publish.

## What Stays Under Your Control

- **Final Editorial Approval**: Articles remain in draft state until a human editor reviews and clicks Publish.
- **Fact Verification**: Review source citations provided by the Perplexity research output before accepting drafts.
- **Brand Voice Standards**: Maintain a dedicated style sheet node that injects company terminology and prohibited clichés into every prompt.

## Starter Prompt

Use this master system prompt in the article drafting node:

```text
You are a senior technology editor writing for technical leaders, engineers, and product operators.

Topic Brief:
Title: {{ $json.title }}
Primary Keyword: {{ $json.keyword }}
Research Context: {{ $json.researchSummary }}

Draft an authoritative 1,200 to 1,500 word technical article in Markdown.
Follow these editorial requirements strictly:
1. Do not use em dashes anywhere. Use commas, colons, or full stops.
2. Structure with an executive summary, technical architecture, step-by-step implementation, and production trade-offs.
3. Every claim must trace to verifiable evidence from the research context.
4. Avoid empty filler phrases such as 'in today's fast-paced world' or 'it is important to remember'.
5. Include a concrete comparison table or code block illustrating the concept.
```

## Customize It

1. **LinkedIn Carousel Generator**: Add an image generation node to automatically create branded 1080x1350 slide images for each major subheading.
2. **SEO Metadata Extraction**: Include a secondary prompt node that generates optimized meta titles, meta descriptions, and slug suggestions.
3. **Multi-Language Localization**: Add translation nodes using DeepL or GPT-4o to generate localized versions for Spanish and German blogs.

## Keep It Reliable

1. **Strict Draft Enforcement**: Hardcode the CMS publication status parameter to `draft` so an unapproved post can never accidentally go live.
2. **Citation Validation**: Implement a regex check verifying that all external links returned by Perplexity use valid secure HTTPS protocols.
3. **Payload Truncation**: When passing research into social spin nodes, extract only the core bullet takeaways to prevent context token overflow.
