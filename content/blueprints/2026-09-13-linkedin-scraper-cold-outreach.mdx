## What You're Building

An end-to-end B2B outbound prospecting pipeline. You input an Ideal Customer Profile (ICP) query or Sales Navigator URL. The workflow runs an actor on Apify to scrape active decision-makers, queries Apollo or hunter APIs to retrieve verified business emails, filters out unqualified prospects, and appends fully-enriched lead profiles directly to Google Sheets or your CRM.

## What Scraping and Apollo Can Handle

Manual prospecting takes hours of copy-pasting names, headlines, and company domains. Automating this pipeline via n8n delivers:

1. High-throughput lead extraction without risking your personal browser account.
2. Two-step email verification to maintain mailbox deliverability above 98 percent.
3. Clean column mapping into Google Sheets with duplicate detection on personal LinkedIn URLs.

## What You Need

1. An Apify account with API token for executing the profile scraper actor.
2. An Apollo API key for real-time B2B contact and email enrichment.
3. An n8n instance to schedule and coordinate the pipeline.
4. A Google Sheets database configured with standardized CRM columns.

## The Build Blueprint

```
[Target ICP Parameters / Search Query]
                   │
                   ▼
[Apify Actor: Profile & Company Scraper]
                   │
                   ▼
[Apollo Enrichment Node: Match Verified Email]
                   │
                   ▼
[Filter Node: Discard Unverified or Inactive]
                   │
                   ▼
[Google Sheets Upsert: Append or Update by LinkedIn URL]
```

## How to Set It Up

1. Open Apify, navigate to the LinkedIn scraper actor, and test a sample run with your search criteria. Copy your Apify API Token.
2. Open Apollo, go to Settings > Integrations > API Keys, and generate a new secret key.
3. In Google Drive, create a new spreadsheet named `B2B Pipeline Leads` with columns: `Full Name`, `Email`, `Title`, `Personal LinkedIn`, `Company Name`, `Company Website`, `Company LinkedIn`.
4. In n8n, create credentials for Google Sheets, Apify, and Apollo.
5. Import the blueprint JSON into n8n and select your Google Sheet ID in the append node.
6. Trigger the workflow manually to verify the first batch of scraped rows.

## The Core Workflows

1. **Lead Extraction**: Submits targeted search criteria to Apify actor and polls for finished run items.
2. **Contact Enrichment**: Sends full name and company domain to Apollo matching endpoints to retrieve direct corporate emails.
3. **Data Hygiene**: Normalizes company names (removes legal suffixes like LLC and Inc) and formats job titles.
4. **CRM Sync**: Runs `appendOrUpdate` against Google Sheets, using the unique LinkedIn profile URL as the match key.

## What Stays Under Your Control

- **Lead Quality Criteria**: Add conditional filter rules for minimum employee headcount, seniority level, or target geography.
- **Daily Volume Caps**: Set batch limits to avoid spam flags and keep within vendor API credit quotas.
- **Outreach Timing**: Hold verified leads in staging before feeding them to cold email sequencing tools like Instantly or Smartlead.

## Starter Prompt

Use this prompt in your LLM personalization node to craft icebreakers:

```text
Review the prospect's LinkedIn summary: {{ $json.summary }}
Company domain: {{ $json.companyWebsite }}
Write a 1-sentence personalized observation about their recent company focus.
Keep it conversational, natural, and avoid generic praise or buzzwords.
```

## Customize It

1. **Cold Email Sequence Hand-Off**: Add an HTTP node pushing verified contacts directly into an Instantly or Smartlead campaign.
2. **AI Icebreaker Generation**: Insert an LLM node that reads the prospect's latest posts and generates custom first lines.
3. **Slack Lead Alerts**: Send real-time Slack notifications when high-value VP or C-level prospects are identified.

## Keep It Reliable

1. **Email Deliverability**: Never send emails to unverified addresses. Enforce catch-all filters to protect sender reputation.
2. **Duplicate Checks**: Always use unique profile URLs as primary keys when syncing with Google Sheets or your CRM.
3. **API Credit Budgets**: Monitor Apify compute unit consumption by scheduling runs once daily rather than continuous polling.
