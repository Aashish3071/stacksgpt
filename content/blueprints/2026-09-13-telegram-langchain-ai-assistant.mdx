## The Problem

Your team wants a quick AI assistant in the chat app they already use. Opening a separate AI website for every question breaks the flow, and simple chatbots forget what you said a moment ago.

## What You'll Get

- An AI assistant on your own Telegram bot.
- Replies that take the recent conversation in each chat into account.
- Images created on request and sent straight back into the chat.

## How It Works

1. Someone sends a message to your Telegram bot.
2. The AI assistant reads it along with the recent conversation.
3. It replies, or creates an image and sends it back.

## What You Need

- A Telegram account, to create your bot with BotFather
- An OpenAI account
- An n8n account to run the workflow
- About half a day to set it up

## Build It Step by Step

1. **Download the workflow file** from the box above and import it into n8n.
2. **Create your bot.** In Telegram, message `@BotFather`, send `/newbot`, choose a name and a handle ending in `bot`, and copy the token it gives you.
3. **Connect Telegram.** Create a Telegram credential in n8n with that token.
4. **Connect OpenAI.** Add your OpenAI API key in n8n.
5. **Check the memory step.** Its session key should be `=chat_with_{{ $('Listen for incoming events').first().json.message.chat.id }}`, which keeps each chat's memory separate.
6. **Turn it on** and send your bot a question, then ask it to draw something.

## Copy-Paste Prompt

Use this as the assistant's instructions:

```text
You are an executive operational assistant accessible via Telegram.
Communicate clearly and concisely, and use bullet points for multi-step answers.
Do not make up facts. If you lack information, ask the user a clarifying question.
If the user asks for an image, send the image link in your final reply.
```

## Good to Know

- **Anyone can message your bot** once they find it. Add a check for allowed chat IDs if it should only serve your team.
- **Memory is short.** The template keeps the last 10 interactions for each chat. Change this in the memory step.
- **Telegram has sending limits.** Its bots FAQ asks bots to avoid more than one message per second in a single chat, and says bulk broadcasts are limited to about 30 messages per second.
- **Split long answers.** Telegram limits how long one message can be, so break long AI replies into several messages.
- **Easy extras.** Add web search, voice note transcription or a step that saves action items to Notion.

## Technical Details

```
[Telegram Trigger Webhook]
           │
           ▼
[LangChain AI Agent Node]
   ├── [OpenAI Chat Model]
   ├── [Window Buffer Memory (Session: chat.id)]
   └── [Tools: Image Generation + Telegram]
           │
           ▼
[Send Telegram Message Response]
```

- **Trigger:** the Telegram Trigger receives each incoming message.
- **Memory:** a window buffer memory keyed by chat ID keeps conversations separate.
- **Image tool:** an HTTP request tool calls OpenAI's image generation API when the user asks for an image.
- **Formatting:** if you enable HTML or Markdown parse modes, sanitize the AI output first, because malformed markup makes Telegram reject the message.
- **Source template:** [Telegram AI Assistant with Image Generation](/blueprints/templates/telegram-ai-assistant).
