## What You're Building

An automated lead qualification and firmographic enrichment pipeline. When a prospective customer submits a contact form, demo request, or waitlist application, this workflow intercepts the webhook payload in real time.

Instead of routing raw submissions to sales reps, an enrichment node parses the company domain, discovers firmographic attributes such as company size, business model, and estimated revenue, and scores the buyer intent against your Ideal Customer Profile (ICP). High-scoring enterprise leads immediately trigger an urgent Slack alert with full briefing context, while lower-scoring leads enter automated nurture sequences.

## What Language Models and Webhooks Can Handle

Manual sales triage slows response time and burns executive hours. Combining automation with LLM data extraction enables:

1. **Instant Domain Dissection**: Extracts corporate email domains, weeding out free webmail addresses like Gmail or Yahoo.
2. **Firmographic Inference**: Synthesizes company industry, business model (B2B, B2C, Marketplace), and estimated funding stage.
3. **Objective ICP Scoring**: Evaluates job titles, team sizes, and stated challenges against predefined scoring criteria.
4. **Conditional Channel Routing**: Automatically dispatches qualified opportunities to dedicated closing channels while logging disqualified inquiries.

## What You Need

1. A form provider (Typeform, Tally, Google Forms, or standard custom webhook).
2. A Google Sheets account for centralized database tracking and CRM backup.
3. An OpenAI API key with access to GPT-4o or GPT-4o-mini.
4. A Slack incoming webhook or bot token.
5. An active n8n instance.

## How to Set It Up

1. Create a Google Sheet with columns for Timestamp, Name, Email, Company, Job Title, Use Case, Score, and AI Summary.
2. In n8n, set up a Webhook node to listen for POST requests from your website contact form.
3. Configure your Google Sheets and OpenAI credentials in your n8n workspace.
4. Import the provided workflow JSON template into n8n.
5. Set the target Google Sheet document ID and Slack sales channel.
6. Submit a test form entry with a corporate domain to confirm proper qualification and routing.

## The Core Workflows

1. **Submission Ingestion**: Receives form submissions containing prospect name, email address, company URL, and initial request text.
2. **Domain Parsing**: Extracts the domain from the email, runs validation, and queries public company information.
3. **Structured Scoring**: GPT-4o evaluates the lead based on job authority, budget indicators, and urgency, returning structured JSON with an integer score from 0 to 100.
4. **Data Syncing**: Appends the parsed firmographic attributes and calculated score into Google Sheets.
5. **VIP Notification**: For leads scoring 75 or higher, posts an interactive Block Kit card into Slack with direct LinkedIn links and contact buttons.

## What Stays Under Your Control

- **Scoring Rubric**: Modify scoring criteria in the system prompt to reflect changing business priorities or ICP updates.
- **Alert Thresholds**: Adjust the score boundary that separates automated email replies from live sales rep outreach.
- **Data Protection**: Store all prospective customer data in your private sheet or CRM without sending sensitive details to external third parties.

## Starter Prompt

Use this prompt in the evaluation node to enforce strict qualification standards:

```text
You are an expert sales operations analyst scoring inbound prospective clients for a high-ticket software service.

Review the following prospect submission:
Name: {{ $json.name }}
Email: {{ $json.email }}
Company: {{ $json.company }}
Role: {{ $json.role }}
Problem Statement: {{ $json.message }}

Scoring Rules:
- Senior decision-makers (Founder, VP, Director, Head of Product): +30 points.
- Mid-level individual contributors: +15 points.
- High-intent technical problem statement: +40 points.
- Vague or student inquiry: 0 to 20 points total.
- Free webmail (gmail, hotmail, yahoo): -20 points penalty.

Output format must be valid JSON:
{
  "score": <number 0-100>,
  "companyTier": "Enterprise" | "MidMarket" | "SMB",
  "urgency": "High" | "Medium" | "Low",
  "executiveSummary": "<2 sentence overview for the sales team>"
}
```

## Customize It

1. **Clearbit or Apollo API Fallback**: Add an HTTP Request node to query Clearbit or Apollo for revenue and employee headcount if domain data is ambiguous.
2. **Calendar Booking Direct Link**: For leads with a score above 85, auto-generate a personalized email reply containing your senior partner calendar scheduling link.
3. **HubSpot or Salesforce Sync**: Replace the Google Sheets node with HubSpot CRM to create deals and assign contact owners automatically.

## Keep It Reliable

1. **JSON Output Verification**: Use n8n JSON schema validation or Structured Output parser to guarantee your LLM returns parseable numerical scores.
2. **Rate Limiting**: Buffer high-volume webhook bursts using an n8n queue mode execution setup during active marketing campaigns.
3. **Bot Spam Filtering**: Include a hidden honeypot field in your web form to drop automated submission spam before triggering API nodes.
