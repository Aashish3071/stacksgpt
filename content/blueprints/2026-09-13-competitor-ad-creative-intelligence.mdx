## What You're Building

An automated ad intelligence and creative production engine. The workflow automatically scrapes active Facebook Ad Library campaigns run by direct competitors in your niche. An OpenAI Vision node analyzes the visual structure, color schemes, headlines, and call-to-action hooks of winning ads. It then rewrites and spins three distinct brand-aligned creative variations and saves the assets into Google Drive and Google Sheets for review.

## What Ad Scraping and Vision Models Can Handle

Manual competitor research is sporadic and rarely turns into ready-to-test ad variants. Automating this system through n8n delivers:

1. Real-time extraction of active, proven competitor creatives without manual screenshotting.
2. Structured visual deconstruction covering typography, layout hierarchy, and copy hooks.
3. Automated folder organization in Google Drive matching source ads with generated variations.

## What You Need

1. An Apify account with access to the Facebook Ad Library Scraper actor.
2. An OpenAI API key with access to GPT-4o vision models.
3. A Google Cloud service account or OAuth credentials for Google Drive and Google Sheets.
4. An n8n instance running on self-hosted Docker or cloud.

## How to Set It Up

1. Open Meta Ad Library in your browser, search for a competitor brand or keyword, and copy the search URL.
2. In Apify, test the Ad Library scraper with that URL and note your target batch size (e.g. 20 ads).
3. In n8n, set up credentials for Apify, OpenAI, Google Drive, and Google Sheets.
4. Import the provided workflow JSON template into n8n.
5. In the Set Variables node, enter your target Google Drive folder ID and brand style guidelines.
6. Run a manual execution to generate your first round of competitor variations.

## The Core Workflows

1. **Ad Harvesting**: Scrapes active ad archive items, filters out text-only listings, and grabs high-resolution image URLs.
2. **Drive Scaffolding**: Automatically creates a dedicated subfolder for each ad archive ID containing `Source Assets` and `Spun Assets`.
3. **Vision Analysis**: Passes image URLs to OpenAI Vision, generating comprehensive descriptions of the design, imagery, and typography.
4. **Creative Variation**: Rewrites ad copy and visual layout directives into distinct creative angles while maintaining winning structures.
5. **Database Logging**: Appends all ad copy, archive IDs, timestamps, and Google Drive asset links to a master Google Sheet.

## What Stays Under Your Control

- **Brand Guardrails**: Define custom style tokens (colors, tone, prohibited terms) so variations respect your brand identity.
- **Competitor Target Lists**: Update search keywords and competitor page IDs dynamically without altering workflow logic.
- **Budget Control**: Restrict the number of variants generated per week to manage image generation costs.

## Starter Prompt

Use this prompt in the creative variation node:

```text
You are an elite direct-response creative strategist.
Review the competitor ad description provided.
Identify the primary emotional hook and value proposition.
Produce 3 distinct variant concepts tailored for our brand.
Keep element placement identical but change color palette, typography style, and primary headline.
```

## Customize It

1. **Direct Ad Account Upload**: Connect the Meta Marketing API node to automatically upload spun assets into your ad account as draft ads.
2. **Video Frame Extraction**: Add an FFmpeg processor node to extract key hooks from video ads and analyze thumbnail performance.
3. **Weekly Slack Summary**: Schedule a weekly roundup message in Slack with the top 5 most durable competitor ads.

## Keep It Reliable

1. **Storage Limits**: Regularly archive older competitor asset folders in Google Drive to manage cloud storage quotas.
2. **Apify Actor Status**: Catch webhook errors when Meta changes DOM structures by enabling error alerts in n8n.
3. **Image Resolution**: Ensure downloaded ad images meet minimum resolution requirements before running vision analysis.
