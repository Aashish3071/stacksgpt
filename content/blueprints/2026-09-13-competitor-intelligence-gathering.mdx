## What You're Building

An autonomous competitive intelligence gathering agent system. Market landscapes move quickly, and founders frequently miss stealth product announcements, pricing restructuring, and new feature launches by competitors.

This system combines semantic neural search (Exa.ai) with multi-agent orchestration in n8n. The primary controller agent periodically searches for similar companies in your sector, spawns sub-agents to retrieve recent news, pricing tables, and user reviews, and synthesizes the findings into a structured comparative matrix inside Notion.

## What Neural Search and Autonomous Agents Can Handle

Standard keyword scraping returns noisy results from irrelevant blogs. Neural search paired with autonomous agents provides:

1. **Semantic Similarity Discovery**: Finds actual direct and indirect market competitors using neural embeddings rather than literal keyword matches.
2. **Targeted Deep Scraping**: Pulls live webpage contents from product pages, changelogs, and pricing tiers without dealing with browser anti-bot blocks.
3. **Structured Feature Extraction**: Maps competitors across standardized dimensions like pricing tier thresholds, core features, and target user personas.
4. **Continuous Notion Dossier Sync**: Updates existing company records when new developments appear and creates new database rows for emerging contenders.

## What You Need

1. An Exa.ai API key with credits for semantic neural search and similarity endpoints.
2. An OpenAI API key with access to GPT-4o.
3. A Notion workspace with an integration token and a dedicated Competitor Intelligence database.
4. An n8n instance with support for advanced AI nodes.

## How to Set It Up

1. Create a Notion database with properties for Company Name, Domain, Value Proposition, Pricing Model, Key Differentiators, and Threat Level (High, Medium, Low).
2. Generate an internal integration secret in the Notion developer portal and share your database with the integration.
3. In Exa.ai, generate an API key and test a basic `findSimilar` query against your website URL.
4. In n8n, create credentials for Notion, Exa HTTP header authentication, and OpenAI.
5. Import the blueprint workflow definition JSON into n8n.
6. Configure your seed domain and execute an on-demand test run to populate your first competitor cards.

## The Core Workflows

1. **Landscape Discovery**: Calls the Exa API `findSimilar` endpoint using your product URL as the baseline, returning top relevant URLs and company domains.
2. **Deep Content Retrieval**: Fetches clean markdown contents of the target company homepage, pricing page, and recent press announcements.
3. **Feature and Pricing Parsing**: Sub-agent prompts parse the retrieved text into strict JSON schema variables representing tiers, feature limits, and integrations.
4. **Competitive Matrix Synthesis**: Reconciles the findings against your company strengths and weaknesses, assigning a tactical threat rating.
5. **Notion Database Synchronizer**: Checks whether the company already exists in your database; updates existing properties or creates a clean new entry with full body notes.

## What Stays Under Your Control

- **Seed Parameters**: Specify exact domains to track alongside automated discovery to ensure key industry incumbents are always included.
- **Threat Scoring Criteria**: Define the criteria for what constitutes a High versus Medium threat based on your specific go-to-market motion.
- **Publication Gate**: Keep newly identified competitors in a Needs Review status until an operator verifies the profile.

## Starter Prompt

Use this prompt in the analysis node to enforce structured competitive breakdown:

```text
You are an expert market intelligence and product marketing specialist.
Review the extracted webpage text from the target competitor company.

Produce a detailed intelligence briefing in JSON format containing:
{
  "companyName": "<official brand name>",
  "website": "<canonical URL>",
  "oneLineSummary": "<concise description of their core offering>",
  "targetAudience": "<primary buyer persona e.g. Enterprise DevOps, SMB Marketers>",
  "pricingStructure": "<freemium, free trial, custom quote, entry price per seat>",
  "coreStrengths": ["<strength 1>", "<strength 2>", "<strength 3>"],
  "vulnerabilities": ["<gap 1>", "<gap 2>", "<gap 3>"],
  "threatLevel": "High" | "Medium" | "Low",
  "threatRationale": "<2 sentence explanation of why they compete with our roadmap>"
}

Ensure all claims are grounded strictly in the provided text. Do not hallucinate capabilities or funding rounds.
```

## Customize It

1. **Changelog and GitHub Release Watcher**: Point an additional scraper node at the competitor public changelog or GitHub releases to catch developer API updates.
2. **Job Board Hiring Signals**: Add a scrape of the competitor careers page to detect aggressive hiring in enterprise sales, security, or machine learning.
3. **Slack Executive Alert**: Send a direct Slack message to the executive team when a new competitor is evaluated as a High threat level.

## Keep It Reliable

1. **Exa Domain Deduplication**: Store known domains in a cache or database filter so the agent does not re-analyze the same competitor on every run.
2. **Markdown Size Truncation**: Truncate raw HTML scrapes to the first 40,000 tokens before sending to the model to avoid context window blowups.
3. **HTTP Timeout Resilience**: Set request timeouts to 30 seconds on the Exa API node to prevent hanging executions during deep web crawl periods.
