## What You're Building

A scheduled content analytics intelligence engine. Rather than requiring marketing leaders to sift through complex Google Analytics reporting dashboards, this automated pipeline runs on a scheduled cadence. It queries 30 days of pageviews, bounce rates, session duration, and organic search conversions across every published article or landing page.

An evaluation node compares current weekly velocity against a 90-day moving baseline. An OpenAI reasoning node interprets the metrics: identifying content decay, highlighting surging traffic clusters, and producing an actionable Slack briefing for the content and growth teams.

## What Google Analytics and OpenAI Can Handle

Standard BI dashboards show numbers without context. Combining programmatic extraction with LLM reasoning delivers:

1. **Automated Data Extraction**: Pulls clean tabular reports from GA4 without manual CSV exports or UI latency.
2. **Anomaly Detection**: Calculates percentage shifts in organic search sessions and flags statistical anomalies.
3. **Decay Warning Alerts**: Pinpoints older cornerstone articles losing ranking positions before organic revenue drops.
4. **Actionable Recommendations**: Recommends internal linking and refresh priorities based on real user engagement data.

## What You Need

1. A Google Analytics 4 property with an active Google Cloud Service Account possessing Viewer access.
2. An OpenAI API key with access to GPT-4o or GPT-4o-mini.
3. A Slack incoming webhook URL or bot token for channel dispatch.
4. An n8n instance (self-hosted Docker or cloud-managed).

## How to Set It Up

1. Open Google Cloud Console, enable the Google Analytics Data API v1, and create a Service Account key in JSON format.
2. In Google Analytics Admin, grant your service account email the Viewer role on your production property.
3. In n8n, create Google Analytics 4 OAuth or Service Account credentials using your client JSON.
4. Add your OpenAI API credential and configure your target Slack webhook URL.
5. Import the blueprint workflow JSON provided below into your n8n workspace.
6. Set your Property ID in the GA4 node and execute a test run to inspect the generated payload.

## The Core Workflows

1. **Metric Extraction**: Queries page path, active users, average engagement duration, and event conversions over the last 7 days compared to the previous 7 days.
2. **Delta Computation**: Normalizes URL paths, filters out administrative backend routes, and computes percentage variance across high-traffic URLs.
3. **Synthesis & Reasoning**: Passes the top 10 gainers and top 10 decliners to GPT-4o to isolate actionable operational takeaways.
4. **Slack Channel Delivery**: Dispatches a cleanly structured Block Kit message with bullet points, green/red status indicators, and refresh recommendations.

## What Stays Under Your Control

- **Threshold Sensitivity**: Set the minimum session threshold (e.g. 500 visits) so low-volume URLs do not trigger false alerts.
- **Reporting Cadence**: Adjust from weekly to daily or monthly schedules depending on your content release volume.
- **Exclusion Filters**: Exclude staging subdomains, preview routes, and tracking parameters from analysis.

## Starter Prompt

Use this system prompt in the analysis node to calibrate your growth insights:

```text
You are an expert content analytics and conversion optimization consultant.
Analyze the following tabular Google Analytics data comparing the current period with the previous period.

Structure your response into 4 distinct sections:
1. Executive Summary: 2 sentences on overall traffic trajectory.
2. Top Growth Outliers: 3 pages with significant positive spikes and probable causes.
3. Content Decay Alerts: 3 cornerstone URLs showing declining traffic or high bounce velocity.
4. Tactical Recommendations: 3 specific editorial actions to take this week.

Maintain an objective tone. Avoid generic advice and cite specific URL paths and percentage changes.
```

## Customize It

1. **Search Console Integration**: Connect the Google Search Console API to pair pageview drops with keyword impression trends.
2. **Automated Jira or Linear Tasks**: Add a branch that automatically opens a content refresh ticket in Linear when an article loses more than 25% traffic.
3. **Multi-Brand Workspace**: Pass dynamic property IDs to loop through client domains for agencies managing multiple client properties.

## Keep It Reliable

1. **Sampling Limits**: For sites with over 10 million visits per month, ensure your GA4 API calls use standard date windows to avoid data sampling.
2. **Dimension Constraints**: Keep dimension combinations under 5 per query to prevent GA4 API quota exhaustion errors.
3. **Webhook Fallback**: Configure Slack error notifications on the workflow failure trigger to catch credential or API quota issues immediately.
