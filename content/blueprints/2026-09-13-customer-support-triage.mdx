## The Problem

Support inboxes mix password resets, billing questions, feature ideas and serious bugs. Someone has to read every message to decide what is urgent, so urgent problems wait behind routine ones and upset customers are spotted too late.

## What You'll Get

- Every new ticket labelled by topic, urgency and the customer's mood.
- A suggested reply for routine questions, waiting for an agent to approve.
- Bugs sent to your engineering tracker and upset customers flagged to your team lead in Slack.

## How It Works

1. A new ticket reaches the workflow from your help desk.
2. AI reads it and labels the topic, urgency and mood.
3. The workflow routes it: a draft reply, an engineering ticket or a Slack alert.

## What You Need

- A help desk that can send new tickets to a web address, such as Zendesk, Help Scout, Intercom or Freshdesk
- An OpenAI account
- A Linear workspace for engineering tickets
- A Slack workspace for alerts
- An n8n account to run the workflow
- About half a day, plus time to combine the building blocks

2. **Start a new workflow** in n8n with a Webhook step, and paste its address into your help desk's outgoing webhook settings.
3. **Add the AI step** and paste in the prompt below.
4. **Add a routing step** with three paths: bugs, upset customers and everything else.
5. **Connect each path.** Create a Linear issue for bugs, send a Slack message for upset customers and save a draft reply in your help desk for the rest.
6. **Test each path** by sending a sample ticket that should go down it.

## Copy-Paste Prompt

Use this in the AI step so every ticket is labelled the same way:

```text
You are an expert customer success operations specialist.
Review the following incoming customer support ticket:

Subject: {{ $json.subject }}
Body: {{ $json.body }}
Customer Plan: {{ $json.planTier }}

Classify the ticket into a strict JSON response:
{
  "category": "Bug" | "Billing" | "Account" | "FeatureRequest" | "GeneralInquiry",
  "urgency": "P1" | "P2" | "P3" | "P4",
  "sentiment": "Positive" | "Neutral" | "Frustrated" | "Hostile",
  "summary": "<one sentence summary of the issue>",
  "isChurnRisk": true | false,
  "suggestedDraftReply": "<polite, empathetic draft response addressing the user directly>"
}

Definitions:
- P1: Total system outage, data loss, or blocking all users.
- P2: Core feature broken with no workaround.
- P3: Minor defect or annoying issue with known workaround.
- P4: Cosmetic bug, question, or feature idea.
```

## Good to Know

- **Replies stay as drafts.** Never let the workflow email customers directly. An agent reviews and sends every reply.
- **Nothing gets dropped.** If the AI step fails, send the ticket to a normal human queue instead.
- **One incident, one bug.** Check for an existing Linear issue before creating a new one, so many reports of the same problem stay together.
- **You choose who skips automation.** Route your most important customers straight to a person if you prefer.

## Technical Details

```
[Webhook: New Customer Support Ticket]
                  │
                  ▼
[OpenAI Classifier: Topic, Urgency & Sentiment]
                  │
                  ▼
[Switch Node: Route Based on Classification]
   ├── Bug / Outage     ──► [Linear: Create Bug Ticket]
   ├── Urgent Sentiment ──► [Slack: Alert Support Lead]
   └── General / How-To ──► [Helpdesk: Draft Knowledge Base Reply]
```

The excerpt below shows the classifier and Linear steps to adapt. It is not a complete workflow.

```json
{
  "name": "Customer Support Triage and Ticket Routing (excerpt)",
  "nodes": [
    {
      "name": "Inbound Ticket Webhook",
      "type": "n8n-nodes-base.webhook",
      "typeVersion": 2,
      "position": [200, 300],

        "httpMethod": "POST",
        "path": "support-ticket",

    {
      "name": "Classify Ticket & Sentiment",
      "type": "@n8n/n8n-nodes-langchain.openAi",
      "typeVersion": 1.8,
      "position": [440, 300],
      "parameters": {
        "messages": {
          "values": [
            {
              "role": "system",

          ]
        }
      }
    },
    {
      "name": "Create Linear Issue",
      "type": "n8n-nodes-base.linear",
      "typeVersion": 1.1,
      "position": [920, 200],
      "parameters": {
        "teamId": "={{ $vars.LINEAR_TEAM_ID }}",
        "title": "={{ $json.summary }}",
        "description": "={{ $json.issueDescription }}"

    }
  ]
}
```
