Perplexity has announced the launch of Portable Computer, a local-first edition of its autonomous agent platform, Perplexity Computer. While the original version relied on centralized cloud servers to coordinate multi-step research and automated tasks, Portable Computer shifts the entire software stack onto user-owned machines.

The platform bundles all essential components of an agent workflow into a self-contained local installation. This includes the task orchestrator, the underlying language model, the tool execution harness, and a local document search index. By keeping all compute on local silicon, the system addresses two major concerns facing enterprise and freelance operators: data privacy and recurring token expenses. Files, proprietary codebases, and financial spreadsheets analyzed by the system never leave the host machine, and local operations incur zero cloud usage billing.

To handle complex queries that exceed local model capacity, Portable Computer uses a hybrid escalation design. Routine document summarization, data extraction, and file management run locally by default. When an assignment demands broader web searches or heavy computational reasoning, the agent requests user permission to escalate the request to Perplexity's cloud infrastructure.

At launch, Portable Computer is available for the Linux-based NVIDIA DGX Spark desktop computer. The initial release supports open weights models including PPLX 27B and Qwen 3.8 27B, with plans to introduce support for the 30-billion parameter NVIDIA Nemotron 3.5 Lightning. Perplexity stated that broader compatibility for personal computers powered by NVIDIA RTX desktop graphics cards will follow.
